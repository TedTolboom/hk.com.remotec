Styr klimaanlegget og start scener med Z-Wave-enheter fra Remotec.

ZXT-120 AC Extender og ZXT-600 AC Master gjør Z-Wave-kommandoer om til infrarøde signaler for split-klimaanlegget ditt. Still inn modus, temperatur, viftemodus og swing fra Homey, les av romtemperaturen, og bruk det innebygde IR-kodebiblioteket eller lær inn kodene fra den originale fjernkontrollen.

Scene Master ZRC-90 gir flytene dine 8 knapper som hver reagerer på ett trykk, to trykk, å holde inne og å slippe.
